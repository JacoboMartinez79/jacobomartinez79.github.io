Windows Forms and wxWidgets Projects

List of Contributions:

Windows Forms: Game of Life

A C# Windows Forms build of Conway's Game of Life, a classic cellular-automaton simulation where a grid of cells lives or dies each step based on how many neighbors it has, producing surprisingly complex patterns from a few simple rules.
  • Programmed the core simulation logic: each generation, I count every cell's living neighbors and apply Conway's rules to decide what the next grid looks like.
  • Built a settings system so the user can change things like grid size and simulation speed, and persist those preferences.
  • Developed the UI, including a HUD showing stats like the current generation and a grid that redraws itself as the simulation runs.

wxWidgets Calculator

A desktop calculator in C++ with wxWidgets, where I used the build as a chance to apply a proper design pattern rather than just wiring buttons to math.
  • Designed and built the calculator's interface, the button grid, display, and input handling, with wxWidgets.
  • Structured the arithmetic with the command pattern: each operation is its own object behind a shared interface, which keeps the logic organized and makes it straightforward to add new operations or support features like undo.
  • Worked through the circular dependency problems that come with C++ headers, untangling the includes so classes that reference each other still compile cleanly.
