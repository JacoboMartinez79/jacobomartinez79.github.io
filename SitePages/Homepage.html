Artificial Intelligence
A path planning system covering everything from BFS to A* for optimal pathfinding, plus flocking algorithms for believable group movement. I built the search graph from tile data and handled hexagonal adjacency across a 2D grid.
Engine Development
A particle system built around sorted and unsorted pools. Active particles stay sorted for efficient rendering, while inactive ones sit in a pool for fast allocation. The result stays smooth even with large particle counts.
Graphics Projects
Graphics work built from the ground up, starting with my own mini linear algebra library for matrix math and line-drawing algorithms, then moving into the DirectX 11 API with a bit of Vulkan along the way.
Computer Networks
A server-client chat app built on the WinSock API with multiplexing. It handles real-time messaging between clients and the server, with support for up to five connections at once.
wxWidgets Projects
Desktop GUI apps built with Windows Forms and wxWidgets. Includes a C# version of Conway's Game of Life and a C++ calculator in wxWidgets that uses the command pattern for undo and redo.
